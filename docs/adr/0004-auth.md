# ADR 0004. 단일 비밀번호 + 짧은 access JWT + 회전 refresh 쿠키

- 상태: 채택 (2026-10-09)
- 결정자: 에이전트 제안(요구사항: 다운로드 시 사용자 인증, 링크 만료)

## 결정
- 계정 없이 비밀번호 한 개(argon2id). 서버에서 `ttakkari set-password` 로만 바꾼다.
- access token: HS256 JWT 15분, 프론트 메모리에만 보관.
- refresh token: 불투명 랜덤값을 HttpOnly 쿠키로, DB 에는 sha256 만. 매번 회전하고, 이미 쓰인 토큰이 다시 오면 같은 계열을 전부 폐기한다.
- 운영(`TTAKKARI_ENV=prod`)에서는 Vercel 프론트와 터널 도메인이 다른 사이트라 쿠키를 `SameSite=None; Secure` 로 낸다.
- 로그인 실패는 IP 별 5회/15분 잠금 + 전역 분당 상한. Cloudflare Tunnel 뒤에서는 `TTAKKARI_TRUST_PROXY_IP_HEADER=CF-Connecting-IP`.
- 다운로드는 5분짜리 별도 audience JWT 링크. 열람은 Bearer 필수.

## 대안
- Cloudflare Access 같은 외부 Zero Trust 를 앞단에 두기: 앱 인증과 겹쳐 두면 더 안전하다. 배포 단계에서 추가 검토(코드 변경 없이 얹을 수 있다).
- TOTP 2단계: 원격 노출 앱이라 가치가 있다. Phase 2 후보.

## 결과
- access token 은 폐기 목록이 없어 `logout-all` 뒤에도 최대 15분 유효하다.
- 일부 브라우저(iOS Safari 의 교차 사이트 추적 방지)는 서드파티 쿠키를 막을 수 있다. 그 경우 프론트와 API 를 같은 상위 도메인 아래 두면 해결된다(배포 때 확인 필요).
