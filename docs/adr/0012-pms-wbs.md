# ADR 0012. 프로젝트 관리 PMS · WBS: 한 작업 표, 두 화면

- 상태: 채택 (2026-10-13)
- 결정자: 사용자. 협업할 때 프로젝트 진행을 한곳에서 보고 고치기 위한 기능. 세부 사양은 나중에 하나씩 조정한다.
- 범위: 프로젝트·작업 트리·마일스톤·이슈/리스크. 외부 사용자 계정·권한·알림·캘린더 연동은 이번에 만들지 않는다.

## 결정

1. **PMS 칸반의 카드 = WBS 의 말단 작업.** 작업은 `pms_tasks` 한 표에 트리(`parent_id`, `position`)로 둔다. 두 화면은 같은 API 를 읽는다.
2. **번호와 집계는 저장하지 않고 읽을 때 계산한다.** `1.1.2` 번호, 상위 작업의 진행률·상태·기간은 `pms/service.py` 가 트리를 펴며 만든다.
   순서·들여쓰기를 바꿔도 어긋날 데이터가 없다. 작업 수는 프로젝트당 2000개, 깊이는 8단계로 제한하니 읽을 때마다 계산해도 비용은 무시할 만하다.
3. **집계 규칙.** 진행률은 자식의 기간(일, 날짜 없으면 1일)으로 가중한 평균. 상태는 전부 done 이면 done, review·done 뿐이면 review, 전부 todo 면 todo, 그 밖은 doing.
   기간은 자식의 가장 이른 시작 ~ 가장 늦은 종료(자식에 날짜가 하나도 없으면 자기 값).
   하위 작업이 있는 작업의 상태·진행률·집계된 기간은 직접 고칠 수 없다(422 `rollup`).
4. **말단의 상태와 진행률은 서로 맞춘다.** done ⇒ 100%, todo ⇒ 0%, 100% ⇒ done, 0% 초과인 todo ⇒ doing, done 을 다시 열면 100% 는 90% 로.
5. **마지막 자식이 사라지면** 상위 작업은 다시 말단이 되는데, 직전에 보이던 집계 값을 자기 값으로 물려받아 화면이 0% 로 튀지 않는다.
6. **선후행은 끝→시작 하나만.** `predecessors` 에 선행 작업 id 를 JSON 으로 둔다. 같은 프로젝트·자기 자신 제외·순환 금지를 서버가 검사한다. 일정을 자동으로 밀어 주지는 않는다(경고 표시용).
7. **담당자·멤버는 이름 텍스트.** 계정/권한 모델이 없다. 프로젝트 `members` 는 자동완성용 이름표다.
8. **변경 API 는 갱신된 전체 작업 목록을 함께 돌려준다.** 번호가 다시 매겨지므로 화면이 한 번에 맞춘다.
9. **내보내기는 화면(브라우저)에서 만든다.** CSV·xlsx 모두 이미 불러온 작업 목록에서 만들어 서버 경로를 늘리지 않는다.
10. **캘린더(`calendar_events`)와는 연결하지 않았다.** 작업 마감을 일정으로 복제하면 두 곳이 어긋난다. 필요해지면 읽기 전용 합성(캘린더가 프로젝트 마감을 조회해 얹기)으로 시작한다.

## 데이터 모델 (0018)

- `pms_projects`: 이름, 설명, `scope`(personal/work), `status`(planning/active/on_hold/done), 시작·종료일, `members`(JSONB).
- `pms_tasks`: `project_id`(CASCADE), `parent_id`(CASCADE), `position`, 제목, 설명, `status`(todo/doing/review/done), `priority`, `assignee`, 시작·종료일, `progress`, `predecessors`(JSONB), `done_at`.
- `pms_milestones`: 제목, `due_date`, `done`.
- `pms_notes`: 이슈·리스크·메모(`kind`), `severity`, `status`(open/resolved), `owner`, 선택적 `task_id`(SET NULL).

기존 테이블은 건드리지 않는다. 프로젝트를 지우면 작업·마일스톤·이슈가 함께 지워진다.

## 나중에 붙일 수 있는 것

- 오케스트레이터 MCP: `/api/pms/*` 는 사용자 API 라 세션 토큰용 `/api/agent/pms/*` 읽기 전용 경로를 같은 `pms/service.py` 로 얹으면 된다(회의록의 `agent_router` 방식).
- 캘린더 읽기 전용 합성, 알림(마감 임박 Push), 프로젝트 템플릿, 일정 자동 밀기.
