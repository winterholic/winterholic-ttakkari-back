# ADR 0025. 요청 시 로드하는 로컬 Whisper와 전사 시도·발화 원본 보존

- 상태: 부분 구현·선택 사용 (2026-10-15). 운영 기본값 변경·배포는 하지 않았다.
- 사용자 요청: 불안정한 클로바노트 브라우저 경로를 대체할 로컬 한국어 회의 STT. 모델 상주 금지.
- ADR 0010의 자체 STT 비범위 결정을 이번 요청 범위에서 갱신한다. ADR 0021의 클로바노트·벡터와 0022의 PMS 연결은 유지한다.

## 결정과 근거

`local_whisper` Provider를 추가한다. 기본 Provider는 `clovanote`, 로컬 설정은 기본 꺼짐이다.
로컬 엔진은 **현재 세션에서 실측 가능한 faster-whisper 1.2.1 / CTranslate2 4.8.3 CPU int8 / large-v3**를 우선 사용한다.
이 선택은 Apple Silicon 최적 엔진 선정의 최종 결론이 아니다. MLX 0.32.4를 실제 설치했으나 이 샌드박스는 Metal 장치를 노출하지 않았다.
whisper.cpp/Core ML은 이번 실행에서 설치·측정하지 않았다. MLX 및 whisper.cpp를 더 빠르다고 추정하지 않는다.

기준선은 동일 large-v3 가중치·int8·한국어·beam 5·temperature 0·word timestamps를 사용한다.
기준선은 VAD 꺼짐·이전 문맥 조건부 생성 켜짐·용어 프롬프트 없음이다.
실험 경로(`improved`)는 Silero VAD, 이전 문맥 차단, 선택 용어 프롬프트를 사용한다.
한국어 공개 낭독 3개에서 CER는 낮아졌으나 WER는 높아져, **기본 로컬 profile은 baseline**이다.
`improved`는 opt-in 설정 또는 구간 재처리 후보로만 제공한다. 전반적인 정확도 개선 주장은 하지 않는다.

## 수명과 큐

1. 기존 업로드 Artifact를 검증하는 `pipeline.request_transcription()`을 재사용한다.
2. `local_stt_jobs`에 queued 시도를 저장한다. 모델을 import하지 않는 비동기 큐 하나가 직렬 처리한다.
3. 회의의 `provider_job_id` 커밋이 보인 뒤 작업을 claim한다. DB 행 잠금·연결은 추론 전에 해제한다.
4. 별도 Python 프로세스가 로컬 모델만 로드한다. 오디오 디코딩은 PyAV, VAD는 faster-whisper 내장 ONNX 자산을 쓴다.
5. 결과를 임시 파일로 받고 자식 프로세스 종료를 기다린다. 성공·실패·시간 초과·취소 모두 자식을 회수한다.
6. 결과·원문 구간을 한 트랜잭션에 저장한다. 기존 `reconcile` → 벡터 색인 → 선택 자동 분석을 재사용한다.

서버 시작은 running 시도를 queued로 되돌리고, 결과 저장 후 전사 상태 반영 전에 끊긴 작업도 이어받는다.
현재 앱의 단일 uvicorn worker 계약을 따른다. 추론 병렬화는 하지 않는다. 대기 큐는 모델을 보유하지 않는다.
워커는 부모 PID 변경을 매초 확인해 부모가 사라지면 프로세스 자체를 종료한다. 이 감시는 단위 테스트했으며 운영 강제 종료·재부팅 상황의 실제 회수 지연은 미측정이다.

## 데이터와 불변식 (Alembic 0025)

- `local_stt_jobs`: 회의·원본 audio Artifact, 상위 시도, 상태, profile·용어·재처리 범위, 원전사, 엔진/런타임/가중치 revision, 음성 SHA-256, 실측 시간·최대 RSS, 오류.
- `local_stt_segments`: 시도별 순번·절대 시작/종료(초), `original_text`, 별도 nullable `corrected_text`, 원시 모델 출력(토큰 포함), word timestamps,
  실제 `avg_logprob`·`no_speech_prob`·`compression_ratio`, 규칙 플래그, 검증 상태, nullable 화자 ID·실제 인물·중첩 여부.
- 원본 녹음은 기존 Artifact에 남고 구간은 Artifact ID와 시간 오프셋으로 연결한다. 관리되지 않는 파일 경로를 API로 받지 않는다.
- 모델이 값을 주지 않으면 null이다. 종합 confidence 수치를 만들지 않는다. 화자·중첩을 실행하지 않았으면 null/not_run이며 단일 화자로 가정하지 않는다.
- 원문은 공백까지 보존한다. 저신뢰·무음 의심·압축률·반복 플래그는 검토 단서이며 삭제·정정 명령이 아니다.
- 프로젝트명·참석자는 제한된 용어 힌트로만 사용할 수 있다. 참석자 이름으로 음성 화자의 신원을 추정하지 않는다.
- 텍스트 재처리 후보는 새 child job이다. 기존 전사·분석·벡터를 자동으로 덮어쓰지 않는다.

## 정렬·재처리와 채택

Whisper가 반환한 word timestamps를 원본 시간축에 옮긴다. 강제 정렬의 정확도까지 검증한 것은 아니다.
별도 화자 구간이 있을 때 시간 교집합·엄격한 과반으로 정렬하는 순수 알고리즘을 테스트했다.
동시 중첩과 순차 화자 교대를 구분하며, 동률은 `speaker_ambiguous`로 둔다. 2차에서 로컬 Community-1 어댑터와 구간·단어 정렬을 연결했다. 실제 가중치 준비 전이므로 추론·DER는 미검증이다.

`POST /api/meetings/{mid}/stt/{job}/reprocess`는 최대 120초의 명시 구간을 다시 추론한다.
모든 후보를 보존하고 자동 반영하지 않는다. 비교 함수는 참조가 있고 CER가 줄며 WER가 늘지 않을 때에만 채택 가능으로 판정한다.
이 함수는 아직 API의 자동 채택 경로에 연결하지 않았다. 클로바 전사도 정답이 아닌 참고 자료이므로 자동 채택 근거로 사용하지 않는다.
2차에서 일반 화자 구간 기반 중첩 탐지·제한 구간 SepFormer 분리·재전사·참조 비교를 연결했다.
참조가 없으면 채택하지 않으며 검수 참조 비교 API도 후보 판정만 반환한다. 합성 표본은 악화되어 채택하지 않았다.
선택 모델·실제 추론 범위와 미검증 항목은 [2차 보고](../stt/phase2-2026-10-15.md)에 따른다.

## 보안·운영 경계

실행 워커는 앱 Settings·DB·환경 파일을 읽지 않는다. 환경 변수는 PATH/HOME/TMPDIR/locale만 허용하며 HF offline·암묵 토큰 사용 금지를 강제한다.
모델 다운로드는 별도 명시 설치 단계에서 `token=False`로 한다. 토큰·키체인·.env를 읽거나 가중치에 인증정보를 저장하지 않는다.
실패 시 API에는 일반 오류와 예외 종류만 남긴다. 회의 원음·개인 전사는 Git에 넣지 않았다.
분석은 기존 Run 계정 정책에 따라 외부 LLM을 쓸 수 있다. 로컬 STT 선택이 분석까지 오프라인으로 만든다는 뜻은 아니다.

## 2차 추가 경계 (2026-10-15)

화자 모델·음원 분리 모델은 서로 독립된 선택 의존성이다. 클러스터는 작업 범위의 익명 ID이며 인물 식별은 실행하지 않는다.
일반 화자 구간과 exclusive 구간을 함께 보존하고, 중첩 판정에는 일반 구간만 사용한다.
누락·실패·예산 초과는 metadata로 구분한다. 새 확률·신뢰도를 만들지 않는다.
명시 용어 교정 미리보기와 한국어·구간 간 반복 플래그는 원문을 삭제·덮어쓰지 않는다.
스키마 변경은 없고 기존 nullable 필드와 job metadata를 사용한다. 운영 설정·기본 provider·배포는 이번 작업에서 변경하지 않았다.
