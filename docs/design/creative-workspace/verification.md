# 검증 기록 · Creative Workspace 시안 (2026-10-15)

대상은 `prototype/`(정적 HTML)이다. 실제 앱·서버·도구와 통신하지 않으므로 **제품 동작 검증이 아니라 시안의 화면·상태·흐름 검증**이다.

## 실행 환경

- Playwright 1.63(`/private/tmp/ttakkari-playwright-node`) + Google Chrome 채널, headless. WebKit(iOS 사파리 엔진) 브라우저는 캐시에 있으나 이번에 쓰지 않았다.
- 뷰포트 390×844(모바일, 터치), 1440×900(데스크톱). 테마는 라이트·다크(`localStorage['tk-theme']`로 강제).

## 명령과 결과

```bash
cd back/docs/design/creative-workspace/prototype
node tools/verify.mjs
```

마지막 실행의 요약 줄:

```
shots: 134 | overflow findings: 0 | a11y findings: 0 | console/page errors: 0
checks: 38 fail: 0
```

- 캡처 134장: 상태 매트릭스 55개 × 모바일/데스크톱 라이트, 대표 12개 × 모바일/데스크톱 다크. `shots/*.png`(저장소에는 커밋하지 않음, 결과함에 있음). `shots/report.json`에 검사 결과 원본.
- 가로 넘침: 문서 `scrollWidth`와 화면 안 모든 요소의 `getBoundingClientRect`를 뷰포트와 비교(의도된 가로 스크롤 칩 줄 안쪽은 제외). 모바일 전체 화면 상세 `dialog`도 포함. 처음 한 번 `work?s=compare&view=overlay`(390)에서 넘침 1건이 나와 `box-sizing`을 고쳤고 재실행해 0건을 확인했다.
- 접근성 자동 검사(직접 작성): 이름 없는 버튼·링크·입력, 중복 id, `alt` 없는 이미지, `h1` 개수. 0건. axe 같은 외부 검사 도구는 쓰지 않았다.

### 흐름·키보드 38개 검사(전부 PASS)

| 영역 | 확인한 것 |

| 승인 | 모달에 승인 대상(파일·버전·해시·v1 보존 문구) 표시, Esc 닫힘, 더블클릭해도 승인 카드 1개, 뒤로가기 복원, 새로고침 후 같은 화면 |
| 비교 | 라디오 ArrowRight → 겹쳐보기, 슬라이더 값 반영 |
| 취소·재시도 | 취소 확인에 남는 것/사라지는 것 설명, 취소 후 상태, 다시 시도 더블클릭 1회 |

| 이력 | 문제 있는 실행이 "완료"로 보이지 않음, 요약줄 "문제 있음 7", 로그 마스킹 |
| 모바일 | 결과물 선택 → 전체 화면 상세, 뒤로가기 복귀, 새로고침 복원(긴 파일명), 상세 가로 넘침 없음, 작업실 상호작용 요소 높이 32px 이상 |

사용한 규칙 검사:

```bash
grep -nE "#[0-9a-fA-F]{3,8}\b" proto.css   # 0건
grep -n "!important\|dark:" proto.css        # 0건
grep -nE "[0-9]px" proto.css                 # 미디어 쿼리 중단점(768·1024·1280)만
```

`proto.js` 안 인라인 `style`은 토큰(`var(--tk-…)`)만 쓰지만 정식 이식 때는 클래스로 옮겨야 한다.

## 미검증(하지 못한 것)

| 항목 | 이유 |
|---|---|
| 13개 앱 실제 설치·연결·기능·버전 | 감사·어댑터 개발은 이번 범위가 아님. 화면 값은 전부 가상 |
| 실제 임베드(iframe/WASM)·CSP/COOP/COEP·postMessage·파일 왕복 | PoC 미실행. 시안은 대화상자와 상태만 |
| 실제 Run·SSE·승인·버전 저장과의 연동 | 백엔드 계약 없음. 시안은 해시 상태만 사용 |
| 실기기(iPhone Safari, 홈 화면 PWA)·터치 제스처·키보드 올라올 때 레이아웃 | 데스크톱 Chrome의 390px 에뮬레이션만 사용 |
| 스크린 리더 낭독 | 미실시. `aria-live` 문구와 이름만 구조 검사 |
| 색 대비 실측 | 미실시. 디자인 시스템 토큰의 검증 리포트에 의존. 임의 색은 쓰지 않았지만 `brand-*`/`blue-300`/`plum-500` 샘플 이미지 색은 사용자 파일 영역이라 대비 검사 대상이 아님 |
| 대용량 목록 성능 | 데이터 8~13건 |
| 다크 전체 매트릭스 | 대표 12개 상태만 캡처. 나머지 상태의 다크는 토큰이 처리한다고 가정하며 눈으로 확인하지 않음 |
| 디자인 시스템 최신 반영 | `ds/`는 `3599f2f`. front가 가진 vendor 복사본과 같은 버전인지는 확인하지 못함 |

## 시각 점검에서 고친 것

- 모바일에서 텍스트 링크 높이 18~26px → `button.tk-link`·행 안 링크에 터치 44px.
- 겹쳐보기 겹침 레이아웃과 `box-sizing`으로 인한 가로 넘침.
- 모바일 작업실에서 실패·취소·연결 끊김 상태 패널이 스크롤 아래에 있던 것 → 미리보기 위로.
- 모바일 컴포저 안내(`명령어 없이 말로 쓰세요`)가 화면을 차지 → 모바일에서 숨기고 비활성 이유 문장은 유지.
