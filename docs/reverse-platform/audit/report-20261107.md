## 판정

**전체 상태: 부분.** 고정한 v2 스냅샷에서 서버의 직접 비교 재계산, 위조·오래된·손상·삭제 증거 거부, 필수 검사, 0건 비교, 회차 전이는 좁은 반례로 확인했다. 다만 독립 검증자가 구현자의 일치 기록을 뒤집을 때 제한 repair가 시작되지 않고, verifier callback 중복이 같은 회차를 history에 한 번 더 넣는다. Backend detail 응답의 실제 모양도 고정 frontend commit의 소비 방식과 맞지 않는다.

### 5. 권한 계약 및 미실행

- **좁은 통과:** 비인증 `POST /api/reverse`는 HTTP 401, agent scope의 work-pool session은 HTTP 403. Workspace 파일 검증은 symlink, 상위 경로 탈출, 절대경로를 거부한다.
- **미검증:** 다중 사용자 간 job/session 소유권 격리와 workspace ACL을 서로 다른 사용자 자격으로 API E2E 하지 않았다. 현재 임시 DB harness는 단일 개인 토큰 흐름에 맞춰져 있다. 따라서 “전체 권한 계약 통과”로 일반화하지 않는다.
- **미실행:** deployed revision `5f5cbd99`의 운영 v2 기능, 실제 외부 API 원본/복제, 실제 웹 browser 원본/복제, UI 렌더링·시각 비교, 최종 운영 감사. 이번 Run은 아직 배포되지 않은 v2 구현 branch의 로컬 고정 스냅샷만 평가했다.
- **미실행:** 전체 테스트 반복 및 구현 worker 테스트 수정. 요청대로 좁은 독립 probes만 실행했고 제품 소스·구현자 테스트는 변경하지 않았다.
