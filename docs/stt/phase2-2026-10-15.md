# 로컬 STT 2차 구현·실측 · 2026-10-15

모델은 앱 배정 gpt-6.1-sol을 그대로 사용했다. 운영 재시작·배포·기본 provider 변경은 하지 않았다.

## 판정

화자·중첩 선택 실행 경로, 용어 교정 후보 API, 반복 검토 플래그를 구현했다.
Community-1 실모델 추론은 정식 로컬 snapshot 준비 전으로 미실행이다. 합성 중첩 분리 표본은 CER/WER가 모두 악화되어 채택하지 않았다.
CPU 6스레드는 회의 첫 180초에서 평균 전체 처리 시간이 11.54% 줄었다. GPU는 이 실행 환경에서 접근 불가하며 가속 수치는 미측정이다.
전체 42분 녹음의 6스레드 개선율이나 실제 다중 화자 회의의 정확도를 이 수치로 대신하지 않는다.

## 구현 범위와 확인 범위

| 항목 | 구현 | 실제 확인·한계 |
|---|---|---|
| Community-1 | 요청 시 로컬 snapshot 로드·익명 화자 수·일반/비중첩 구간 별도 보존·STT 구간/단어 정렬 | 라이브러리 import·어댑터/부정 대조·통합 단위 검사. 실모델 추론·화자 수 오차·DER 미측정: 약관/가중치 준비 전 |
| 불확실 구간 | 엄격한 과반으로 화자 연결. 동률 speaker_ambiguous, 교대 speaker_change, 미포함 speaker_uncovered, 동시 발화 overlapping_speech | 규칙 플래그이며 확률·신뢰도·정답 판정이 아님 |
| 인물 식별 | 음향 클러스터와 별도 metadata 계층. identity_status=not_run, speaker_identities={} | 이름 자동 연결·성문·회의 간 동일인 연결은 실행하지 않음 |
| 중첩 탐지 | 일반 화자 구간의 서로 다른 ID 동시 활성 구간 계산. 중복 주석 합집합, 순차 교대 구분 | 알고리즘 검사. 실제 탐지 precision/recall 미측정: Community-1/중첩 주석 없음 |

| 비교·채택 제한 | 구간별 두 전사를 순열 비교. CER 엄격 감소, WER 비증가, 빈 트랙 금지. 정답 없으면 보류 | 앱은 원문을 자동 변경하지 않음. 명시 검수 참조 API도 후보 판정만 반환 |
| 용어 교정 | 원문 기준 비연쇄 literal 치환 미리보기 API. 별도 corrected_text | 원본·분석·DB 교정 필드 유지. 자동 고유명사 추정 없음 |
| 반복·환각 의심 | 기존 모델 지표 + 한국어 무공백 구절 반복/연속 구간 반복 플래그 | 발언 삭제 없음. 환각률·오탐률 미측정: 사람 판정 없음 |
| 수명·비밀 경계 | 일회용 자식 HOME/HF_HOME·오프라인·token=False·telemetry 비활성화. 시간 초과/취소/실패 회수 유지 | CPU 측정 16회 process_exited=true. 실제 물리 메모리 반납 지연은 미측정 |

원음과 원시 STT 구간을 유지하며, 분리 트랙은 구간 내부 번호로만 다룬다. Community-1 화자나 인물 이름에 자동 매핑하지 않는다.
비교 기준은 동일한 원음 구간을 다시 전사한 결과와 그 구간의 분리 후 전사다. 회의 전체 원전사에서 문장을 잘라 정답처럼 취급하지 않는다.
CER/WER는 두 화자의 내용을 연결하여 측정하는 텍스트 지표다. 화자별 귀속·발화 순서·시각 정확도·cpWER·DER를 뜻하지 않는다.

## CPU 처리 시간: 같은 입력, 4/6/6/4 순서

faster-whisper 1.2.1 / CTranslate2 4.8.3 / large-v3 / CPU int8 / improved / beam 5 / 한국어 / 용어 힌트 없음.
각 설정 2회, 각 실행마다 새 워커. 원음 SHA-256·범위·decode options 일치를 검사했고, SHA를 의도적으로 바꾼 부정 대조도 탐지했다.
다른 모델 추론과 겹친 첫 실행은 제외하고 보존했다(`cpu-threads-preliminary.*`). 아래 최종 실행에는 다른 모델 추론을 병행하지 않았다.
운영 백엔드·OS 부하는 완전히 통제하지 않았으며 통계적 유의성 판정이나 일반 처리량 보증은 아니다.

| 표본 | 길이 | 4스레드 전체 벽시계 평균 | 6스레드 평균 | 시간 감소 | 전사 일치 |
|---|---:|---:|---:|---:|---|
| FLEURS ko/test 0 | 12.48초 | 8.570초 | 7.393초 | 13.72% | 4회 일치 |
| FLEURS ko/test 1 | 10.80초 | 8.442초 | 7.065초 | 16.31% | 4회 일치 |
| FLEURS ko/test 2 | 8.94초 | 8.009초 | 6.732초 | 15.95% | 4회 일치 |
| 기존 회의 첫 180초 | 180초 | 29.561초 | 26.149초 | 11.54% | 4회 일치 |

회의 구간의 원시 시간은 4스레드 29.483/29.639초, 6스레드 26.077/26.221초다.
최대 RSS는 각각 3,811,016,704 / 4,091,265,024 bytes였다(각 두 실행의 최대값). 이 표본에서는 6스레드가 메모리를 더 썼다.
공개 세 표본은 두 설정 모두 CER 7/132=5.30%, WER 14/40=35%다. 전사 일치가 실제 회의 정답률을 증명하지는 않는다.
기본 4스레드 및 baseline profile은 유지한다. 기획 세션이 이 Mac에서 속도를 우선할 때 설정 6을 선택할 수 있지만 전체 장시간·동시 작업 검증은 별도다.

원시 측정: [16회](evidence/phase2/cpu-threads.json), [요약](evidence/phase2/cpu-summary.json), [입력·종료 부정 대조](evidence/phase2/input-check.txt).
1차 42분 29초의 859.294초 추론 / RSS 11.337GB는 [1차 보고](measurement-2026-10-15.md)의 값이다. 이번 180초 비교와 직접 나누지 않는다.

## 합성 중첩: 분리 후보 기각

[Google FLEURS](https://huggingface.co/datasets/google/fleurs) 한국어 test 0/1을 각각 RMS 0.05로 맞추고 동시 시작으로 합쳤다(끝은 0 padding).
평가 데이터는 CC BY 4.0, 출처 Google FLEURS 및 [논문](https://arxiv.org/abs/2205.12446)이다.
길이 12.48초, 혼합 PCM SHA-256 `b0c8020f9c4c1c6d2c32bed6c60380aae6f44a8f710610966ad57f5be10b64c7`.
혼합 구간은 합성 과정으로 아는 구간을 제공했다. Community-1이 탐지한 결과가 아니다. 자연 회의 중첩·잡음·반향의 대표 표본도 아니다.

| 지표 | 원음 구간 STT | 분리 두 트랙 STT | 판정 |
|---|---:|---:|---|
| CER | 57/98 = 58.16% | 72/98 = 73.47% | 악화 |
| WER | 23/29 = 79.31% | 25/29 = 86.21% | 악화 |
| 채택 | 원음 유지 | adopt=false | 기각 |

다른 추론을 병행하지 않은 재실행은 분리 로드 0.448초·분리 추론 1.800초, 원음 STT 7.323초·분리 두 트랙 STT 합계 19.613초였다.
최대 RSS 4,475,568,128 bytes이며 exit 0 및 종료 후 PID 부재를 확인했다. 첫 동시 실행은 별도 preliminary JSON으로 보존했다.

원시 텍스트와 참조도 [공개 비교 행](evidence/phase2/synthetic-overlap-text.json)에 보존했다.
분리 가중치 revision은 `9950fd8055b38679d2af5bef2366b5dba600ec66`이고 세 tensor SHA-256은 [원시 결과](evidence/phase2/synthetic-overlap.json)에 있다.
분리 음원 자체는 재처리 워커의 일시 데이터이며 Git/DB에 저장하지 않는다. 원음·범위·모델 버전·전사 후보로 재현한다.
운영 분리 모델 설정은 기본 null이다. 개선 표본 없이 활성화하거나 회의 본문에 자동 반영하지 않는다.

## GPU·MPS 진단

[원시 probe](evidence/phase2/gpu-probe.json): Torch 2.8.0 MPS built=true / available=false / CUDA=false.
실제 MPS 텐서 생성은 RuntimeError. macOS Metal API MTLCreateSystemDefaultDevice는 null.
MLX import도 exit 1, No Metal device available. 하드웨어가 GPU를 갖고 있다는 사실과 이 실행 주체의 접근 권한을 구분한다.
GPU/MPS·Core ML의 로드/추론/메모리/속도 개선은 **미측정: 현재 실행 환경에서 Metal 장치 접근 불가**다.
GPU 가능한 별도 실행 환경에서 같은 입력으로 다시 재야 한다. 권한을 올리거나 운영 앱을 재시작하지 않았다.

## 재현 명령·검증

backend 루트에서 실행했다. 모델·manifest·개인 원음/전사는 저장소 밖 `testing/ttakkari-stt`에 있다.
실험 스크립트는 [CPU](evidence/phase2/scripts/cpu-benchmark.py), [중첩](evidence/phase2/scripts/overlap-benchmark.py)에 보존했다.
스크립트의 경로 상수는 이 Mac 실측 위치이며 다른 환경에서는 준비한 모델·데이터 위치에 맞춰 바꾼다.

```sh
.venv/bin/python docs/stt/evidence/phase2/scripts/cpu-benchmark.py
/Users/winterholic/testing/ttakkari-stt/venv/bin/python docs/stt/evidence/phase2/scripts/overlap-benchmark.py
/Users/winterholic/testing/ttakkari-stt/venv/bin/python docs/stt/evidence/phase2/scripts/gpu-probe.py
TTAKKARI_TEST_DB=postgresql+asyncpg://localhost/ttakkari_stt_phase2_20261015 .venv/bin/pytest tests/test_local_stt*.py -q --tb=short
TTAKKARI_TEST_DB=postgresql+asyncpg://localhost/ttakkari_stt_phase2_20261015 .venv/bin/pytest -q --tb=short
.venv/bin/ruff check src/ttakkari/meetings/local_stt src/ttakkari/api/meetings.py src/ttakkari/config.py tests/test_local_stt*.py
```

- [로컬 검사](evidence/phase2/local-tests.txt): 59 passed in 8.94s (1차 35개 + 신규 24개).
- [전체 pytest](evidence/phase2/pytest-full.txt): 589 passed, 2 xfailed in 128.66s.
- [린트](evidence/phase2/ruff.txt): All checks passed! 새 API 블록 정렬 전후 AST도 일치했다.
- 새 기능 검사의 최초 실패 로그는 같은 evidence/phase2의 red-*.txt에 보존했다.
- migration·frontend 코드는 이번에 변경하지 않았다. 실제 pyannote 추론·브라우저 실화면·운영 검증까지 통과했다는 뜻은 아니다.
- 선택 extra lock을 갱신했고 기존 1차 lockfile 패키지 버전은 모두 유지했다.

## 남은 것·사용자 조치

1. [Community-1 공식 모델 카드](https://huggingface.co/pyannote/speaker-diarization-community-1)의 조건에 동의하고, 사용자가 직접 인증한 설치 절차로 전체 snapshot을 로컬에 준비한다. 모델 경로만 있으면 되며 토큰 값을 전달할 필요는 없다. 실제 화자 수·DER·회의 단어 정렬은 그 뒤 검증한다.
2. 동의·권한을 갖춘 한국어 실회의의 시간별 전사·화자·중첩 정답 표본을 준비해야 탐지·누락·환각·화자/분리 정확도를 측정할 수 있다. 클로바 전사를 정답으로 승격하지 않는다.
3. GPU 접근 가능한 작업 환경에서 MPS/MLX/Core ML을 실측한다. 이 세션에서는 접근 우회·권한 변경·운영 재시작을 하지 않는다.
4. 분리 모델은 개선이 입증되지 않았다. 한국어에 적합한 모델/조건 재검토와 독립 표본이 필요하다. 3인 이상·15초 초과/총 예산 초과는 현재 건너뛴다.
5. 42분 전체의 4/6스레드 비교, 1시간 입력, 강제 정렬 정확도, 물리 메모리 해제 지연은 미측정이다.
6. LM-SPT는 1차의 논문·코드 검토와 제외 결정을 유지한다. [라이선스 표](lmspt-and-licenses.md)에 이번 선택 의존성·가중치도 추가했다.

프론트 UI 변경·실화면 검증·운영 배포는 이번 범위에서 실행하지 않았다. 기존 클로바 경로·원전사·분석/PMS/벡터는 유지한다.
