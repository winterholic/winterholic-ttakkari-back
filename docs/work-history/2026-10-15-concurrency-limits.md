# 역할별 실행 상한 확대 (2026-10-15)

- 사용자 요청: 동시 실행 제한이 너무 낮고 접수 6·기획 4·작업 6의 차이가 부자연스러우니 넉넉하게 변경.
- 변경: `config.py`의 접수·기획·작업/일반 대화 기본 상한을 각각 16으로 통일. 역할별 독립 세마포어, 계정 사용량 한도, 기획당 활성 작업 세션 20개 상한은 유지.
- `.env.example`과 README에 남은 미사용 `TTAKKARI_MAX_CONCURRENT_RUNS=3` 안내를 실제 세 필드로 교체하고 ADR 0013에 변경 이력과 재시작 필요성을 기록.
- 검증: 기존 코드에서 16개 진입 검사가 `desk: only 6/16 requests admitted`로 실패한 뒤 수정. 실제 RunManager 세마포어를 사용하는 일회성 비동기 검사에서 각 역할의 16개 허용·17번째 대기·자리 반환 후 재개 및 역할 독립·환경변수 상한 2 적용을 확인. `ruff check src/ttakkari/config.py` 및 `git diff --check` 통과. 운영 설정 로더로 출력한 다음 시작 값은 모두 16. 에이전트 CLI를 48개 실제 기동하는 부하 검사는 미실행.
- 운영 상태: 실행 중 프로세스의 세마포어는 캐시되므로 아직 6/4/6일 수 있다. 이 요청에서는 배포·재시작하지 않았다. 다른 세션의 다수 미커밋 변경이 있는 공유 저장소이며 타 작업을 커밋하거나 재시작하지 않음. 다음 승인된 백엔드 배포에서 적용·운영 API 확인 필요.
