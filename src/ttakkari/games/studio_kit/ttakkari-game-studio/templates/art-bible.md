# 아트 바이블 (에셋을 만들기 전에 채운다)

모든 장면이 같은 게임으로 보이게 하는 한 장짜리 기준이다. 비어 있으면 에셋 생성을 시작하지 않는다.

- 화풍 한 줄(예: 굵은 외곽선 + 평면 채색, 3톤 음영):
- 팔레트(주색 3 + 보조 3, HEX):
- 캐릭터 비율·실루엣 규칙:
- 해상도·스프라이트 시트 규격(프레임 크기, 프레임 수, 투명 배경 여부): `asset-rules.json` 에도 옮긴다
- 폰트·UI 패널 스타일(게임 안 UI 는 게임 엔진 안에서 그린다. 웹 UI 컴포넌트를 올리지 않는다):
- 금지(사용자가 싫어한다고 말한 표현):
- 기준 이미지(contact sheet 캡처 경로):
