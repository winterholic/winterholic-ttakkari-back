# 버티컬 슬라이스 체크리스트 (장 전체를 만들기 전에 한 장면만 끝까지)

한 장면을 최종 품질로 먼저 만든 뒤 사용자 확인을 받고, 나머지를 같은 기준으로 확장한다.

1. 장면 하나를 고른다(가장 자주 보게 될 곳):
2. 조작: 이동·공격·상호작용이 처음 10초 안에 이해되는가? (재생 증거: play-replay)
3. 보기: 실제 렌더 화면 캡처 3장(시작·교전·결과). 자리표시자·체커 이미지 없음.
4. 소리: 호출 확인(헤드리스는 청취 불가이므로 사용자 확인 대기로 표시).
5. 막힘: 도달성 검사 통과, 모든 입력 모드(키보드·터치)에서 진행 가능.
6. 사용자에게 보여 줄 한 줄 요약과 캡처 경로:
7. 사용자 확인 전에는 나머지 장면에 같은 설계를 복제하지 않는다.
